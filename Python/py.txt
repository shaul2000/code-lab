What is Python?:
Python is a programming language that reads almost like English. It's used for:
    - Web apps (Instagram, Dropbox)
    - Data & AI (ChatGPT, Netflix recommendations)
    - Automation (sending emails, renaming 1000 files at once).

History: Created by Guido van Rossum in 1991, named after 
Monty Python (not the snake 🐍).

How Python Code Runs:
You write code → Python reads it line by line.

Your code (.py file)
      ↓
Interpreter (reads it)
      ↓
Bytecode (middle-level, machine-friendly)
      ↓
Result on your screen
You don't need to memorize this. Just know: Python runs top to bottom, one line at a time.

Conditions & Decision Making
1. Comparison Operators (The Question Askers)
These operators compare two values and ask: "Is this true or false?" They always return a Boolean (True or False).

- Operator: ==
- Meaning: Equal to
- Example: 5 == 5
- Result: True

- Operator: !=
- Meaning: Not equal to
- Example: 5 != 3
- Result: True

- Operator: >
- Meaning: Greater than
- Example: 5 > 3
- Result: True

- Operator: <
- Meaning: Less than
- Example: 3 < 5
- Result: True

- Operator: >=
- Meaning: Greater than or equal to
- Example: 5 >= 5
- Result: True

- Operator: <=
- Meaning: Less than or equal to
- Example: 3 <= 5
- Result: True

Common Mistake: Use == to compare. Use = to assign.
-x = 5: "Put 5 in x"
-x == 5: "Is x equal to 5?"

2. if, elif, else (The Decision Tree):
This is how Python makes choices. It works like a fork in the road.

How it works:
- Python checks the first if. If True, it runs that block and skips everything else.
If the first if is False, it checks the
- elif ("else if"). If all if and elif are False, it runs the 
- else block.
Key Rule: Only one block runs.

3. Logical Operators (Combining Questions)
You can combine multiple conditions using and, or, not.

- Operator: and
- Meaning Both must be True
- Logic: True and True → True

- Operator: or
- Meaning At least one must be True
- Logic: True or False → True

- Operator: not
- Meaning: Reverses the value
- Logic: not True → False

Tuples & Dictionaries:
TUPLES 🔒
What is a Tuple?
A tuple is like a list, but locked. Once created, you cannot add, remove, or change items.

- List → [] → Changeable ✏️
- Tuple → () → Locked 🔒

Tuples are used for dat that should not change - birth date, coordinates, constants, it's safer.

Unpacking a Tuple (The Cool Trick)
Instead of grabbing items one by one, you can unpack them into separate variables in one line.
birth_date = (1998, 5, 14)

year, month, day = birth_date   # Unpacking!

print(f"Born on {day}/{month}/{year}")
#How it works: Python matches the items left-to-right:
- year gets 1998
- month gets 5
- day gets 14

⚠️ The number of variables must match the number of items, or Python crashes.

DICTIONARIES 📖
What is a Dictionary?
A list uses numbers as positions (list[0]). A dictionary uses names (keys) as labels.

Think of a real dictionary: you look up a word (key) to find its meaning (value).

Syntax: Uses curly braces {} with key: value pairs.

⚠️ The Trap: If you use a Key that doesn't exist, Python crashes with an error!
The Safe Way: Use .get() to avoid crashing. It returns None (or whatever you ask it to return) if the key is missing.

Creating, Accessing, Updating, Adding, Deleting:
1. Creating (The Setup)
You create a dictionary using curly braces {}. Inside, you write key: value pairs separated by commas.

student = {
    "name": "Emmanuel",
    "age": 24,
    "is_active": True
}

- "name" is the Key (the label/keyword).
- "Emmanuel" is the Value (the data).
Rule: Keys must be unique. You can't have two "name" keys. Values can be anything (text, numbers, lists, etc.).

2. Accessing (Getting Data)
To get data out, you use the Key inside square brackets [].
print(student["name"])   # Output: Emmanuel
print(student["age"])    # Output: 24

3. Updating (Changing Existing Data)
To change a value, you use the Key again on the left side of the = sign.
student["age"] = 25   # Change age from 24 to 25

print(student["age"])   # Output: 25
Note: You cannot change the Key itself. If you want to rename a key, you have to delete the old one and add the new one.

4. Adding (New Data)
To add a new item, you just create a new Key that doesn't exist yet.
student["city"] = "Lagos"   # "city" didn't exist before

print(student)
# Output: {"name": "Emmanuel", "age": 25, "city": 'Lagos'}

Rule: If the Key exists → Update. Rule: If the Key is new → Add.

5. Deleting (Removing Data)
To remove a key-value pair, use the del command.

del student["age"]   # Remove the "is_active" item

print(student)
# Output: {"name": "Emmanuel", "city": "Lagos"}

⚠️ The Trap: If you delete a key that doesn't exist, Python crashes.
The Safe Way: Use .pop() or .popitem().

THE WHILE LOOP: 
A while loop says: "Keep doing this As Long As the condition is True."

for vs while loop
- use the for loop when you know how many times to repeat.
- use while when you don't know -- it depends on a condition.

- use the for loop when looping over lists/strings/dictionaries.
- use the while loop when waiting for user input or an event.

break, continue, pass
These control what happens inside a loop.

- break → Stop the loop immediately
- continue → Skip this round, go to next
- pass → Do nothing (a placeholder)


Nested Loops (Loop Inside a Loop):
A nested loop runs the inner loop completely for each repetition of the outer loop.

FUNCTIONS
Think of a function as a tool or a recipe. Instead of writing the same code over and over, you write it once, give it a name, and then you can "call" it whenever you need it.
What is a Function?
A function is a block of code that performs a specific task.
- Defining a Function (The "Blueprint")
When you define a function, you are not running the code inside it yet. You are just creating a blueprint. Python reads this line and says, "Okay, I've saved this block of code under this name. I won't do anything with it until I'm told to."

Key Rules for Defining:
- def: The magic keyword.
- function_name: Must follow Python naming rules (starts with a letter, no spaces, no numbers at the start). It's best practice to use snake_case (e.g., calculate_total, get_user_data).
- (): Parentheses are mandatory, even if empty.
- :: The colon is mandatory. Without it, Python throws a SyntaxError.
- Indentation: The very first line inside the function must be indented (usually 4 spaces). If it's not indented, Python thinks it's outside the function.

- Calling a Function (The "Action")
Calling a function means executing the code inside it. You do this by typing the function's name followed by ().

Parameters and Return Values:
- Parameters:
These are placeholders for data you want to put inside the function.
- Calling with Arguments
This is the actual data you pass in.

Return Values:
Functions can give back a result so you can use it later.
Note: Once return is hit, the function stops immediately. Any code after return is ignored.

Default Arguments:
You can set a "backup" value for parameters. If the user doesn't provide one, the function uses the default.

*args and **kwargs (The "Too Many" Arguments):
*args (Arbitrary Arguments):
Use this when you don't know how many positional arguments (numbers/items) will be passed. It collects them into a tuple.

**kwargs (Keyword Arguments)
Use this for named arguments (keyword = value). It collects them into a dictionary.

Variable Scope (Local vs Global)
- Local: Variables created inside a function exist only there.
- Global: variables created outside exist everywhere.

Lambda Functions & Docstrings:
- Lambda
A lambda function is a tiny, anonymous (nameless) function defined in a single line. You use them when you need a simple function for a very short time, and you don't want to bother writing def.
Syntax:
lambda arguments: expression

- Docstrings (The "User Manual"):
A docstring is a special string written inside a function to describe what the function does. Unlike comments (#), docstrings are stored inside the function's metadata and can be read by Python (and other developers) using help().

How to Write One:
Place a triple-quoted string ("""...""") as the very first thing inside the function.

Why Use Docstrings?:
- Self-Documentation: Anyone reading your code (including future you!) will instantly know what the function does.
- Built-in Help: You can type help(square) in the interactive Python shell, and it will print your docstring!

Docstrings vs Comments:
Feature	Comments (#)	            Docstrings ("""...""")
Purpose	Explain how or why	      Explain what the function does
Visibility	Hidden from Python	      Stored in __doc__
Access	None	                        help(function_name)
Location	Anywhere	                  First line of the function
