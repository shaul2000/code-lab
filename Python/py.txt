What is Python?:
Python is a programming language that reads almost like English. It's used for:
    - Web apps (Instagram, Dropbox)
    - Data & AI (ChatGPT, Netflix recommendations)
    - Automation (sending emails, renaming 1000 files at once).

History: Created by Guido van Rossum in 1991, named after 
Monty Python (not the snake 🐍).

How Python Code Runs:
You write code → Python reads it line by line.

Your code (.py file)
      ↓
Interpreter (reads it)
      ↓
Bytecode (middle-level, machine-friendly)
      ↓
Result on your screen
You don't need to memorize this. Just know: Python runs top to bottom, one line at a time.

Setup:
 1. Install Python from python.org → tick "Add Python to PATH" during install
 2. Install VS Code from code.visualstudio.com
 3. In VS Code, install the Python extension
 4. Create a folder, make a file called hello.py
 5. Run it in the terminal with: python hello.py

 print() and Comments:
 # = comment. Anything after # on that line is not run.
 print("Hello World"): Prints the text "Hello World" to the screen.

Variables:
A variable is a box that stores a value. You give the box a name.

The 4 core data types:
1. - Type: str
      - Means: string/text
      - Example: "Lagos"

2. - Type: int
      - Means: integer/whole number
      - Example: 25

3. - Type: float
      - Means: decimal number
      - Example: 1.75

4. - Type: bool
      - true or false
      - Example: True 

Check any type with type():

Type Conversion:
Sometimes you need to change one type into another.
Common conversions: int(), float(), str()

Strings, Numbers & User Input
1. String Methods (Tools for Text):
      Strings (text) have built-in tools called methods. You use them with a dot (.).

            # .upper() and .lower():
                  - Make text all caps or all lowercase.

            # .split():
                  - Break a long sentence into a list (array) of words.

            # .replace():
            Swap one word for another.

2. Indexing and Slicing (Grabbing Parts of Text):
      Think of a string as a row of boxes, numbered starting from 0.

      - String: "  K  e  l  v  i  n  "
      - Index:   0  1  2  3  4  5  6

            # Indexing ([0]): Get one letter.
            # Slicing ([start:end]): Get a chunk of letters.
                  - Start is inclusive (included).
                  - End is exclusive (NOT included).

3. f-strings (The Modern way to print):
      Instead of using the + or the , to join text and variables, use f before the quote. 
      It's cleaner and easier. and also gives you control over the spacing so it 
      appears how you typed it and not adding spacing.
      - Why it's better: You don't need str() or +. Just put the variable name inside {}.

            
4. Arithmetic Operators (Math):
- Operator: +
- Meaning: Addition
- Example: 5 + 2
- Result: 7

- Operator: -
- Meaning: Subtraction
- Example: 5 - 2
- Result: 3

- Operator: *
- Meaning: Multiplication
- Example: 5 * 2
- Result: 10

- Operator: /
- Meaning: Division (always float)
- Example: 5 / 2
- Result: 2.5

- Operator: //
- Meaning: Floor Division (whole number)
- Example: 5 // 2
- Result: 2

- Operator: %
- Meaning: Modulo (remainder)
- Example: 5 % 2
- Result: 1

- Operator: **
- Meaning: Exponent (power)
- Example: 5 ** 2
- Result: 25


Conditions & Decision Making
1. Comparison Operators (The Question Askers)
These operators compare two values and ask: "Is this true or false?" They always return a Boolean (True or False).

Operator: ==
Meaning: Equal to
Example: 5 == 5

Common Mistake: Use == to compare. Use = to assign.
-x = 5: "Put 5 in x"
-x == 5: "Is x equal to 5?"

2. if, elif, else (The Decision Tree):
This is how Python makes choices. It works like a fork in the road.

How it works:
- Python checks the first if. If True, it runs that block and skips everything else.
If the first if is False, it checks the
- elif ("else if"). If all if and elif are False, it runs the 
- else block.
Key Rule: Only one block runs.

3. Logical Operators (Combining Questions)
You can combine multiple conditions using and, or, not.

- Operator: and
- Meaning Both must be True
- Logic: True and True → True

- Operator: or
- Meaning At least one must be True
- Logic: True or False → True

- Operator: not
- Meaning: Reverses the value
- Logic: not True → False

4. Truthiness (Everything has a "True/False" value):
In Python, not just booleans can be true or false.

- Value: True
- Truthiness: ✅ True

- Value: False
- Truthiness: ❌ False

- Value: 5, 10.5, 100
- Truthiness: ✅ True (Non-zero numbers)

- Value: 0, 0.0
- Truthiness: ❌ False (Zero)

- Value: "Hello"
- Truthiness: ✅ True (Non-empty text)

- Value: ""
- Truthiness: ❌ False (Empty text)

- Value: None
- Truthiness: ❌ False
